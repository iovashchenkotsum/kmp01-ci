# Если первая сборка не прошла

Не чините в одиночку больше 15 минут: напишите в чат курса (Telegram-чат группы, который ведёт вуз), что видите, приложив текст ошибки. Самые частые случаи:

| Что видите | Что сделать |
|---|---|
| `SDK location not found` | File → Settings → Languages & Frameworks → Android SDK: путь к SDK должен быть заполнен. Если пусто — Edit и установить |
| Gradle качает бесконечно или `Could not resolve…` | Проверьте, не режет ли загрузки антивирус или VPN; повторите синхронизацию: File → Sync Project with Gradle Files |
| Путь с кириллицей: ошибки вроде `Malformed…`, `Unable to…` в `C:\Users\Имя\…` | Перенесите проект в папку с латинским путём, например `C:\kmp\kmp01`; SDK — в `C:\Android\sdk` (File → Settings → Android SDK → Edit) |
| Эмулятор не запускается, `HAXM`/`WHPX`/`Hyper-V` в тексте ошибки | Включите виртуализацию в BIOS (Intel VT-x / AMD-V); на Windows включите Windows Hypervisor Platform: «Включение или отключение компонентов Windows». Или подключите телефон по USB |
| `Unsupported Java`, `Gradle JDK` | File → Settings → Build Tools → Gradle → Gradle JDK: выберите «Embedded JDK» (JetBrains Runtime) |
| Studio старее 2026.1.4, проект не открывается или просит обновить плагин | Help → Check for Updates, обновить Studio и плагины |
| `git` не найден | Установите Git (раздел 3) и перезапустите Studio |
| При push: `Error in the HTTP2 framing layer` | Повторите push; если повторяется — в терминале выполните `git config --global http.version HTTP/1.1` |
| При push просит логин и пароль | Введите логин и пароль от аккаунта GitFlic, поставьте «Remember» |
