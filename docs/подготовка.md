# Подготовка к курсу «Кроссплатформенные технологии»

На занятиях мы будем собирать одно приложение на Android и iOS в общем проекте. Чтобы на первом занятии 6 октября не ждать загрузок, подготовьте машину заранее — это займёт около часа, из них большая часть — ожидание. Сделайте всё до **4 октября**, чтобы осталось время задать вопрос в чат курса, если что-то не соберётся.

## Что понадобится

- Ноутбук с Windows, macOS или Linux, **16 ГБ памяти** (на 8 ГБ работать можно, но эмулятор будет медленным) и 20 ГБ свободного места.
- Интернет без ограничений на скачивание: Android Studio, SDK и зависимости проекта — около 5 ГБ.
- Mac и Xcode **не нужны**: iOS-сборку показывает преподаватель.

## 1. Аккаунт на GitFlic — 5 минут

1. Откройте [gitflic.ru](https://gitflic.ru) → «Регистрация»: логин латиницей, почта, пароль. Подтвердите почту по письму. Можно войти через VK ID или Яндекс ID — тогда аккаунт создастся сам.
2. Логин станет частью адреса вашего проекта, поэтому выберите тот, который не стыдно показать: `gitflic.ru/project/<логин>/kmp01`.

## 2. Форк курсового проекта — 2 минуты

1. Откройте [gitflic.ru/project/kmp-course/kmp01](https://gitflic.ru/project/kmp-course/kmp01).
2. Нажмите «Форк». Владелец — вы, имя `kmp01` не меняйте, приватность — публичный. Нажмите «Создать».
3. Скопируйте адрес получившегося проекта: `https://gitflic.ru/project/<ваш-логин>/kmp01`.

## 3. Git — 5 минут

- **Windows:** установите [Git for Windows](https://git-scm.com/download/win) с настройками по умолчанию.
- **macOS:** откройте Терминал и выполните `git --version` — система предложит установить инструменты командной строки, согласитесь.
- **Linux:** `sudo apt install git` или аналог вашего дистрибутива.

## 4. Android Studio — 20 минут

1. Скачайте [Android Studio](https://developer.android.com/studio) — версия **Quail 4 | 2026.1.4** или новее. Если у вас уже стоит более старая, обновите: Help → Check for Updates.
2. Установите с настройками по умолчанию. При первом запуске мастер настройки скачает Android SDK — согласитесь со всем, что предлагает, и примите лицензии.
3. Отдельно ставить JDK не нужно: всё необходимое приходит со Studio и с проектом.

## 5. Эмулятор — 10 минут

1. В Android Studio: Tools → Device Manager → «+» → Create Virtual Device.
2. Телефон — любой из списка (например, Pixel 9 или Medium Phone), образ системы — последний предложенный (API 35 или 36; на Windows и Intel-Mac — x86_64, на Apple Silicon — arm64). Скачайте образ, нажмите Finish.
3. Запустите эмулятор кнопкой ▶ в Device Manager и дождитесь рабочего стола Android. Если есть Android-телефон, он подойдёт вместо эмулятора: включите на нём отладку по USB.

## 6. Клон форка и первая сборка — 30 минут ожидания

1. В Android Studio на стартовом экране: **Clone Repository** (в открытом проекте: File → New → Project from Version Control). URL — адрес **вашего форка** с `.git` на конце: `https://gitflic.ru/project/<ваш-логин>/kmp01.git`. Папка — любая **без кириллицы и пробелов в пути**.
2. Нажмите Clone и **ждите**. Первая синхронизация Gradle скачивает Kotlin, Compose и Android-плагин — от 10 до 20 минут в зависимости от сети. Индикатор внизу окна должен дойти до конца без красных сообщений.
3. Выберите конфигурацию `androidApp` вверху окна, рядом — ваш эмулятор или телефон, нажмите ▶. Первая сборка — ещё несколько минут.
4. **Готово, когда** на эмуляторе открылось приложение с надписью «Кинопоиск».

## Что в итоге

Три вещи к 6 октября: аккаунт на GitFlic, ваш форк `kmp01`, приложение «Кинопоиск» запускается на вашем эмуляторе или телефоне. Остальное — на занятиях.
