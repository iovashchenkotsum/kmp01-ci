# KMP-курс: клиент Кинопоиска

Учебный проект курса «Кроссплатформенные технологии разработки мобильных приложений». Один код — два приложения, Android и iOS. Здесь лежит то, с чего каждый вечер начинается работа; ваш код живёт в вашем форке.

## До первого занятия (до 6 октября)

1. **Аккаунт на GitFlic** — [gitflic.ru](https://gitflic.ru): логин, почта, пароль, подтверждение по письму. Можно войти через VK ID или Яндекс ID.
2. **Форк.** На странице этого проекта нажмите «Форк», владельцем оставьте себя, имя не меняйте. Получится `gitflic.ru/project/<ваш-логин>/kmp01`.
3. **Android Studio** — версия **Quail 4 | 2026.1.4** или новее, JDK ставится вместе с ней. Создайте эмулятор: Device Manager → Create Device, любой телефон, последний образ.
4. **Клон форка.** В Android Studio: File → New → Project from Version Control, URL — адрес **вашего форка** с `.git` на конце. При первом push GitFlic спросит логин и пароль от аккаунта — те же, что на сайте.
5. **Дождитесь синхронизации Gradle** — первая занимает 5–15 минут, качаются Kotlin, Compose и Android-плагин. Зелёная сборка — значит, машина готова.

Если что-то не собралось — не чините в одиночку: на первом занятии на это отведено время, а типичные ошибки собраны в `docs/ошибки-первой-сборки.md`.

## Как устроена работа

- **`upstream`** — этот репозиторий. Перед каждым занятием сюда выкладывается тег `start-N`: код к началу вечера N, включая эталон домашнего N−1. Добавьте его один раз:

  ```
  git remote add upstream https://gitflic.ru/project/kmp-course/kmp01.git
  ```

- **Каждый вечер начинается с эталона**, а не с вашего вчерашнего кода:

  ```
  git fetch upstream --tags
  git checkout -b lab-N start-N
  ```

  Ваше домашнее при этом не пропадает — оно остаётся в своей ветке и в запросе на слияние.

- **Домашнее** делается в ветке `hw-N`, продолжающей работу вечера:

  ```
  git checkout -b hw-N          # от lab-N; на первом вечере — от master
  git push origin hw-N
  ```

- **Сдача** — запрос на слияние **внутри вашего форка**: на странице форка «Запросы на слияние» → «Создать». Источник — ваш форк, ветка `hw-N`; **Цель — ваш форк, ветка `master`** (не `kmp-course/kmp01`). Заголовок — `hw-N`, в описании — то, что просит README задания. Срок — до следующего занятия. Сливаете сами после проверки.

## Домашние задания

Лежат в `homework/NN/README.md` с условием, именем файла, куда класть код, и тем, что смотрит проверяющий. Первое — `homework/01`: экран заказа на Java переписать на Kotlin.

## Куда не заходить

`build.gradle.kts`, `settings.gradle.kts`, `gradle/` — сборка настроена, менять её на курсе не нужно. `androidApp/…/MainActivity.kt` и `iosApp/` — точки входа платформ, они тоже готовы.
